# Blinkit Sales Analysis | Power BI

## Project Overview
An interactive Power BI project analyzing Blinkit sales, product categories, outlet performance, and customer ratings.

## Business Objectives
- Analyze overall sales performance.
- Compare sales across outlet types, outlet sizes, and outlet locations.
- Identify high-performing product categories.
- Explore fat content, item visibility, and ratings.

## Tools Used
- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel

## Dashboards
### 1. Executive Overview
Key performance indicators, sales trends, and category-level performance.

### 2. Outlet Performance
Sales comparisons by outlet location, outlet size, and outlet type.

### 3. Product Insights
Item-type sales, fat-content analysis, ratings, and item visibility.
